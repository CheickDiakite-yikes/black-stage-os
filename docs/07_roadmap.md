# 07 Roadmap

## Roadmap philosophy

Do not try to build the full OS first.

Build the new interaction primitive first. Then attach more real capability over time.

The roadmap moves from:

1. Cinematic prototype.
2. Real conversation.
3. Real artifacts.
4. Real agents.
5. Real integrations.
6. Personal operating environment.
7. Ambient agentic OS.

## Phase 0: Foundation

### Objective

Create the repo, docs, operating model, tracking system, and first design direction.

### Deliverables

- Repo initialized.
- AGENTS.md installed.
- Product docs installed.
- Tracker workbook installed.
- Basic app scaffold.
- Design tokens.
- Research logging templates.

### Exit criteria

- Codex can understand the mission and run build commands.
- Cheick can assign the first three engineering tasks.
- The team has a shared product language.

## Phase 1: Stage Shell v0

### Objective

Prove the living render field.

### Deliverables

- Full-screen black stage.
- Intent input.
- Intent threads.
- Render cards.
- Simulated agent feed.
- Approval card.
- Artifact card.
- Demo fixtures.
- Research instrumentation.

### Exit criteria

- A viewer understands that this is not a chatbot.
- The stage can turn a spoken/typed intent into a visible workspace.
- A short demo produces the "I saw the future" reaction.

## Phase 2: Real conversation and artifact engine

### Objective

Move from simulation to model-backed conversation and artifact creation.

### Deliverables

- Real LLM conversation layer.
- Voice input and speech output.
- Structured response to render manifest.
- Artifact generation for memos/plans/research notes.
- Thread export.
- Better memory/context summaries.

### Exit criteria

- The system can create useful artifacts from real user intent.
- The render field updates from model-generated structure.
- Voice/text interaction feels natural enough for daily use.

## Phase 3: Agent runtime and approval system

### Objective

Introduce real delegated work under strict human control.

### Deliverables

- Agent task model.
- Tool adapter abstraction.
- Safe sandboxed local actions.
- Approval policy engine.
- Audit log.
- Cancellation/redirect controls.
- Real status/evidence events.

### Exit criteria

- Agents can perform bounded useful tasks.
- Users can see and govern work.
- Risky actions require approval.
- Audit trail is usable.

## Phase 4: Knowledge work operating layer

### Objective

Connect Blackstage to real knowledge workflows.

### Deliverables

- File/document portals.
- Browser/research portal.
- Calendar/email integrations where permitted.
- Project memory.
- Artifact library.
- Workspace search.
- Intent-thread-based project management.

### Exit criteria

- A founder can use Blackstage for daily knowledge work.
- Intent threads become more useful than folders or chat history.
- Artifacts can move into real workflows.

## Phase 5: Multi-agent command center

### Objective

Coordinate multiple agents across complex workflows.

### Deliverables

- Agent roles.
- Parallel tasks.
- Subagent summaries.
- Conflict resolution.
- Human-in-the-loop planning.
- Agent performance metrics.
- Task replay and evaluation.

### Exit criteria

- Multiple agents can work without creating chaos.
- Human supervision stays elegant.
- The system can handle long-horizon projects.

## Phase 6: Personal cognitive OS

### Objective

Make Blackstage the user's primary interface for thinking, planning, creating, and executing.

### Deliverables

- Long-term memory vault.
- Personal preference model.
- Cross-device continuity.
- Private data boundaries.
- Voice-native daily workflow.
- Proactive but permissioned suggestions.
- Deep artifact management.

### Exit criteria

- Users start work in Blackstage before opening apps.
- The underlying desktop fades into the background.

## Phase 7: Ambient reality interface

### Objective

Extend from computer interface to reality interface.

### Deliverables

- Multimodal physical-world perception.
- Wearable/room interfaces.
- Robotics/device actions where safe.
- Ambient context.
- Real-world approval rituals.
- Personal AI operations center.

### Exit criteria

- Blackstage mediates between human intent and both digital and physical environments.

## Roadmap guardrails

- Never trade trust for autonomy.
- Never add broad integrations before approval/audit foundations.
- Never allow the interface to become cluttered.
- Never hide uncertainty.
- Never let the product drift into generic assistant UX.
- Always preserve the living render field.
