# 13 Checklists

## New Codex task checklist

- [ ] Task has a clear objective.
- [ ] Relevant docs are named.
- [ ] Acceptance criteria are explicit.
- [ ] Verification commands are listed.
- [ ] Product constraints are stated.
- [ ] Research logging requirement is included.
- [ ] Scope is small enough for a reviewable diff.

## PR checklist

- [ ] Builds successfully.
- [ ] Typecheck passes.
- [ ] Lint passes.
- [ ] Tests pass or missing tests are justified.
- [ ] Demo fixture updated if relevant.
- [ ] UI still feels like Blackstage.
- [ ] Agent activity remains visible.
- [ ] Risky actions are approval-gated.
- [ ] Research events/logs updated if relevant.
- [ ] Docs updated if behavior changed.

## Stage Shell v0 checklist

- [ ] Full-screen black stage.
- [ ] Center presence.
- [ ] Text input.
- [ ] Voice input experiment or placeholder.
- [ ] Intent thread creation.
- [ ] IntentCard.
- [ ] PlanCard.
- [ ] AgentActivityFeed.
- [ ] ApprovalCard.
- [ ] ArtifactCard.
- [ ] Demo fixtures.
- [ ] Simulated agent event stream.
- [ ] Local persistence.
- [ ] Research event logging.
- [ ] Exportable session log.

## Demo checklist

- [ ] Clear demo narrative.
- [ ] No private data.
- [ ] App starts cleanly.
- [ ] First five seconds feel magical.
- [ ] Intent creates visible structure.
- [ ] Agent feed shows useful labor.
- [ ] Approval moment appears.
- [ ] Artifact is created.
- [ ] No broken UI.
- [ ] Session can be recorded.
- [ ] Observations are logged.

## Security checklist

- [ ] No secrets in code.
- [ ] No private data in logs.
- [ ] No external side effects without approval.
- [ ] Destructive actions require explicit confirmation.
- [ ] Memory writes are scoped.
- [ ] Approval history is stored.
- [ ] Simulated actions are labeled.
- [ ] Research logs are privacy-safe.

## Research session checklist

- [ ] Date/session id recorded.
- [ ] Objective recorded.
- [ ] Prompt/task recorded.
- [ ] Outcome recorded.
- [ ] Human interventions recorded.
- [ ] Product insights recorded.
- [ ] AI-building insights recorded.
- [ ] Evidence links recorded.
- [ ] Open questions recorded.

## Weekly founder review checklist

- [ ] What changed in product?
- [ ] What changed in code?
- [ ] What did Codex do well?
- [ ] What did Codex repeatedly get wrong?
- [ ] What changed in AGENTS.md or docs?
- [ ] What research findings emerged?
- [ ] What is the next highest-leverage demo improvement?
- [ ] What should be killed or simplified?
